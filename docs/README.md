# boss-helper-plus 源码分析文档

- 分析对象：当前工作区中的 `boss-helper` 源码（衍生版本 `0.0.1`，代码基线来自上游 `0.5.2.2`）
- 分析方式：静态阅读源码、配置、构建脚本与 GitHub Actions，不依赖联网资料

## 项目一句话总结

boss-helper-plus 是一个基于 **WXT + Vue 3 + shadcn-vue + Tailwind CSS** 的浏览器扩展：它把一段脚本注入 Boss 直聘页面的主世界，通过页面自身的 Vue 实例读取职位列表和详情，用一套**可插拔的任务管线**完成筛选、AI 评估、投递和打招呼，并把 UI 放在 Shadow DOM 的右侧抽屉中，避免占用宿主页面布局、也不修改页面原有 DOM。

> 本项目仅供学习交流，禁止用于商业用途。使用自动化投递存在账号风控风险，详见 [11-已知限制与风险.md](./11-已知限制与风险.md)。
